# Cobblemon: Battle Showdown

A Cobblemon addon that adds a **team preview** to PvP battles: before the battle starts, both players see each other's team and choose their lead Pokémon.

## ✨ Features

- **Team preview screen**: your team on the left, your rival's team on the right.
- **Lead selection**: click a Pokémon to send it out first.
- **Timers**: 30 seconds to choose, then a 5 second countdown before the battle starts.
- **Forfeit on timeout**: if only one player chose in time, the other one forfeits. If nobody chose, the battle is cancelled.
- **Level-adjusted formats**: the preview shows the levels and HP the battle will actually use.
- **Multiplatform**: Fabric and NeoForge from a single codebase.
- Currently enabled for **singles** battles only.

## 📋 Requirements

| | Version |
|---|---|
| Minecraft | 1.21.1 |
| Java | 21+ |
| Cobblemon | 1.8.1+ (below 1.9.0) |
| Fabric Loader | 0.17.2+ with Fabric API and Fabric Language Kotlin |
| NeoForge | 21.1.182+ with Kotlin for Forge |

The mod must be installed on **both** the server and the clients.

## 📦 Installation

1. Install [Cobblemon](https://cobblemon.com) and its dependencies for your loader.
2. Download the jar for your platform (`battle_showdown-fabric-*.jar` or `battle_showdown-neoforge-*.jar`).
3. Place it in your `mods` folder.

## 🔧 Building

```bash
# Build every platform (jars end up in fabric/build/libs and neoforge/build/libs)
./gradlew build

# Run a development client
./gradlew :fabric:runClient
./gradlew :neoforge:runClient
```

## 🗂️ Project structure

The build follows the [cobblemon-contenders](https://github.com/team-relic/cobblemon-contenders) template (Architectury Loom, Mojang mappings, Kotlin DSL).

```
common/    Shared code: battle logic, networking, GUI and mixins
  src/main/kotlin-templates/   Pebble templates (build details generated by Blossom)
fabric/    Fabric entrypoints and networking implementation
neoforge/  NeoForge entrypoint and networking implementation
```

Mod id, version and dependency versions live in `gradle.properties`.
